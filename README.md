# Brain Battle

Flutter MVP for a quiz game.

## Run
1. Install Flutter.
2. Create/open this project.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Included
- Splash screen
- Home dashboard
- Categories
- Quiz timer
- Scoring
- XP and levels
- Coins
- Results
- Profile
- Local leaderboard

This version is offline. Firebase, real-time multiplayer, authentication, cloud leaderboards, and an admin panel should be added as the next development stage.
